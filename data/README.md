# Planetary dataset

File: planets.csv

This starter dataset contains ten Solar System objects: the eight planets, Earth's Moon, and Pluto (a dwarf planet). Numerical values are transcribed from the planetary fact-sheet table supplied during project planning and should be checked against the source before final submission.

## Important caveats
- Empty numeric cells mean unknown or unavailable; do not replace them with zero without justification.
- Moon counts can change as new moons are confirmed.
- The Moon's distance, perihelion, and aphelion values in this starter table refer to its orbit around Earth, not an orbit around the Sun. Exclude the Moon from planet-only solar orbital analysis.
- Rotation periods may be negative in source tables to indicate retrograde rotation. Keep this convention documented.
- Temperature, pressure, and other values depend on the source's definitions.
- Pluto is classified as a dwarf planet, and the Moon as a natural satellite.
- Include the original source URL, access date, units, and any corrections in the final report.
